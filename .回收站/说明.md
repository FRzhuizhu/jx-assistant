# .回收站 —— 从仓库根目录搬出来的 Go 单测

**为什么在这里**：2026-09-28 按用户要求，把根目录的 28 个 `*_test.go` 从主包搬出
（用户判断这些测试实际价值不大，不想让它们继续占着仓库根目录、也不希望 `go test .`
被它们拖时间）。不是删掉——文件都还在，随时能搬回去。

**为什么目录名以 `.` 开头**：Go 工具链（`go build ./...`、`go vet ./...`、`go test ./...`）
自动忽略点号/下划线开头的目录，所以这些测试文件放在这里**不会被编译**，不会因为
引用了主包内部符号而报错；同时也从普通目录列表里隐掉。

**怎么搬回去**（在仓库根目录执行）：

```powershell
cd "D:\Desktop\童浩\智能体工作目录\软著版数字助理"
Get-ChildItem ".回收站" -Filter "*_test.go" | ForEach-Object { git mv $_.FullName ".\$($_.Name)" }
go test .
```

**搬出去之后的现状**：`go test .` 会提示没有测试文件并直接通过；`go build .` 不受影响；
前端 `gui-test/` 下的 CDP 脚本（含 `cdp.mjs` 公用驱动）**没有动**，仍在原位。
