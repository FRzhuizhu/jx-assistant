MD查看器 —— 双击 .md 文件，独立窗口渲染打开
================================================

这是什么
--------
坚祥数字助理套件里的独立小应用。双击 .md 文件（或在本数字助理的对话里
点击 .md 文件路径）时，弹出一个独立窗口，用系统浏览器内核（WebView2，
与数字助理桌面版同一内核）渲染显示，样式与原来的网页预览完全一致。
不依赖 Python，数字助理没在运行也能单独使用。

文件说明
--------
- MD查看器.exe         主程序（双击 .md 时系统调用的就是它）
- viewer-template.html 查看器模板（样式与渲染库都在这一个文件里）
- Microsoft.Web.WebView2.*.dll / WebView2Loader.dll   WebView2 运行组件
- install.ps1          一键注册 .md 文件关联（右键 -> 使用 PowerShell 运行）
- 还原关联.ps1          一键还原到安装前的打开方式
- 原关联备份.txt        安装前的原始关联值（自动备份）

怎么设为 .md 默认打开方式
------------------------
右键本目录的 install.ps1 -> 使用 PowerShell 运行，完成。
之后双击任何 .md 文件都会弹出「MD查看器」独立窗口。
（也可以不设默认：右键 .md -> 打开方式 -> 选择「MD查看器」单独用一次）

常见问题
--------
1. 双击 .md 没反应 / 还是别的程序打开？
   重新运行一次 install.ps1；或右键 .md -> 打开方式 -> 选择「MD查看器」
   并勾选「始终使用此应用」。

2. 提示「未检测到 WebView2 运行时」？
   会自动改用系统默认浏览器打开（功能不丢）。建议安装
   Microsoft Edge WebView2 Runtime 获得独立窗口体验。

3. 打开后的网页文件存在哪？
   系统临时目录（%TEMP%\mdviewer），随用随生成，清理后会自动重建。

4. 图标还是旧样子？
   重启一次资源管理器或电脑即可刷新。

5. 如何彻底卸载？
   右键「还原关联.ps1」-> 使用 PowerShell 运行，然后删除整个 md-viewer 文件夹。

开发者说明（仅开发机相关）
--------------------------
- 源码与构建在 智能体工作目录\md-viewer\（本目录是随安装包分发的运行产物，
  build.ps1 会自动同步过来）。
- 改了 MDViewer.cs / 图标 / 模板后：在开发目录运行 build.ps1 重新编译并同步。
