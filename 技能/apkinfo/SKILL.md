# APK 查看技能（apkinfo）

引擎自带子命令，桌面与安卓同一用法。安装 APK 之前**先验包再安装**：
确认包名与签名证书主体是预期厂商，再动手。

## 用法

引擎可执行文件的绝对路径见环境快照的「引擎程序」行。

```
<引擎程序> apkinfo <file.apk>            # 人读输出
<引擎程序> apkinfo <file.apk> --json     # JSON 输出
```

输出字段：包名、应用名、版本名(版本号)、min/target SDK、ABI、权限清单、
签名证书 SHA-256 与主体（DN）。

## 判读要点

- **签名主体是验真核心**：如官方 DeepSeek App 主体为 `CN=DeepSeek,O=DeepSeek`；
  主体是个人名、空 DN 或与厂商不符时，视为来路不明，不要安装，如实上报。
- `targetSdk` 过低（如 < 23）的包在安卓上属老应用，安装行为可能受限。
- 权限清单里出现与其功能无关的高危权限（如计算器要「短信」）要向用户指出。
- v1/v2/v3 签名方案差异不影响本命令；只装了一个签名块时取的是 v1(JAR) 证书。

## 平台注意

- 安卓上没有 aapt2/apksigner/keytool，本子命令是唯一验包手段，不要试图
  现场寻找或安装这些 Java 工具。
- 纯 Go 实现，依赖已随引擎内置，无需联网、无需 root。
