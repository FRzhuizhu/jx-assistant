任务执行

最大步数
单条消息触发的任务里，模型可连续执行的步数（模型调用＋工具执行）上限；连续跑满这个数仍未完成会自动停止

本页偏好保存在本机浏览器；最大步数保存在服务端（即时生效）。

网络访问

局域网访问（同一 Wi-Fi）

允许手机/平板访问

开启后同一局域网内的设备都能打开并使用本助手（含文件与命令工具），请只在自己可信的网络开启。改动需重启程序后生效；首次开启时 Windows 防火墙弹窗请点「允许访问」。

远程接入（公网中继）

允许外网设备访问

经自建网关的加密中继（端到端 AES-256-GCM，网关只见密文）从外网访问本助手；手机入口为网关配对页（下方地址含配对密钥，收藏即可自动连接）。改动即时生效；知道配对密钥的人都能使用本助手，请妥善保管密钥。

设备号

手机入口路径 /a/设备号，在同一网关上须唯一；每台安装默认自动生成，可改成自己好记的（2~32 位字母/数字/中划线/下划线）。

配对密钥

端到端加密密钥的种子，同时是接入凭证；每台安装默认自动生成独立的随机密钥（8~64 位）。换新密钥后，旧入口链接立即失效。

网关地址 / 端口

中继网关（210 网关 server.js）的域名或 IP 与端口，不带 http:// 前缀；给别人分发本软件时，这里应改成对方自己部署的网关。

市场（技能 / 组件 / 插件）

市场服务器

jxai-server 市场的清单地址（同一台服务器上与中继网关共用端口）；填好即用，改动即时生效。留空则市场页显示未配置。

网络访问设置保存在服务端；远程接入改动即时生效，局域网绑定改动重启程序后生效。

模型

一家提供方配一个 API 密钥，可挂多个模型；预置提供方直接用系统存好的地址，自定义提供方才需要填 API 地址。点击卡片即可展开编辑。改完点底部的「保存」即可；卡片里的「保存」只提交这一家提供方。

对话历史与压缩

原始历史永久保留，压缩只影响发给模型的内容

文件备份

文件历史快照

write_file / edit_file 与 snapshot_file 的改动前内容会存进工作区的 .jxai/snapshots，供编辑历史消息或按轮撤销时回退文件；关闭后不再记录新快照。

自动清理（天）
超龄快照每天清一次；填 -1 表示永不过期

文件备份保存在服务端，改动即时生效。

子对话专家

名称即调用参数：主对话派发子对话时填 expert=名称，追加提示词、默认模型与上下文继承完全按该专家的预设生效（换模型可用 model 参数）。下方每个名称与后端可调用的专家清单同源一致；停用的专家对主对话不可见；名称要保持唯一。

内置专家 常开，不可修改

自定义专家 可开关、可编辑、可删除

内置组件

来自 组件/ 的原生外围扩展；开关即时生效，无需刷新

技能

技能 = 带 SKILL.md 说明与脚本的能力包。用户技能装在 技能/user/（手动拖入目录同样有效）；开启后只把名称与描述列入技能清单，模型使用时先 read_skill 读完整说明。

自带技能 常开，不可删除

用户技能 可开关、可删除

插件

来自 插件兼容层/；开关即时保存，界面部分刷新页面后生效

Claude 插件

兼容 Anthropic Claude Code 插件格式（plugin.json + skills/commands/agents/hooks/MCP）。技能、命令、专家装好后即可用；hooks / mods / MCP 属执行型组件，默认关闭、需在此显式开启。输入框里输入 / 可触发插件命令。

已安装 开关即时保存；卸载会删除本地缓存
