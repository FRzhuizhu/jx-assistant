# 按对话的组件/插件开关（会话级覆盖）— 改动说明与验证步骤

日期：2026-11-07　｜　一句话：每个对话可以有自己的组件/插件生效集（优先于全局
开关、全局开关不动），加号菜单一键打开设置页同款浮窗管理，切换会话时热装配。

## 用户设计（照做）

1. 对话输入区**加号菜单**加一个按钮「本对话的组件与插件」——针对**当前对话**
   控制启用哪些插件/组件；全局开关不动（别的对话关的这里可以开、开的这里可以
   关），持久按会话存。
2. 点开是**设置页同款浮窗**，只显示「组件」「插件」两个一级页（各二级页照常），
   各插件/组件自己注册的设置页也展示（排在组件/插件之下，如语音的设置）。
3. 复用现有组件热开关机制（CX 注入/卸载，即点即生效）。
4. 后端：会话级覆盖配置（优先于全局开关），会话切换时按当前会话的覆盖集装配。

## 改动清单

### 后端

| 文件 | 改动 |
|---|---|
| `sessioncx.go`（新） | 会话覆盖注册表：存会话附属数据 `sessdata:cx-overrides:<会话id>`（meta 表，随会话删除一并清），只记显式覆盖、拨回与全局一致即删；`cxoComponentEnabled/cxoPluginEnabled`（生效＝覆盖优先于全局）、`cxoComponentLive`（「全局或任一会话要它」的存活口径）、`cxoComponentList/cxoPluginList`（会话生效视图，带 `globalEnabled/override`）、`sessionCustom`（本会话是否定制过） |
| `components.go` | `GET /api/components?s=<会话id>`＝会话生效视图；`POST` 带 `session`＝写会话覆盖（全局不动）；worker 杀灭加守卫（全局关且无任何会话要它才杀）；资产端点 `?s=` 按会话放行；`ComponentStatus` 增 `globalEnabled/override` |
| `server.go` | `GET/POST /api/plugins` 同款会话参数；会话删除时 `SessionCX.forget`；`NewApp` 载入覆盖 |
| `pluginlayers.go` | `LayerPlugin` 增 `globalEnabled/override` 字段 |
| `store.go` | `Delete` 顺带清该会话全部 `sessdata:*`（此前只清 laststop，一直漏） |
| `componentbridge.go` / `voiceapi.go` | 组件桥端点与语音端点的开关口径改 `cxoComponentLive`：会话把全局关着的组件打开时端点可用（请求不带会话，按最宽松口径；会话关掉的对话里 UI 已热卸载不会来请求） |
| `ccplugin_commands.go` / `ccplugin_mod.go` | 斜杠命令按会话生效集过滤：`/api/cc-plugins/commands?s=`、插件命令与 mod 命令的展开/执行前查会话覆盖 |

## 边界与有意不做

- **模型工具目录仍按全局开关装配**（`toolsFor` 只认模式不认会话）：会话里关掉
  git-panel/todo 组件后，git_sync/todo 工具仍在目录里、按全局口径执行。完整会话化
  要把会话传进 `toolsFor`（改动在 agent.go 的调用点），本轮明确避开（另有任务在动
  agent.go）。
- 插件（CC）的 MCP 工具/技能等模型侧目录同样按全局；会话覆盖对插件即时生效的
  部分是斜杠命令（清单+展开+mod 命令）。
- 浮窗里不带安装/卸载、CC 执行型组件开关/配置（全局性操作，归 设置 → 插件）。

## 验证（已完成）

单测（`go test -run 'TestSessionCX|TestComponentEnabled' .`）：覆盖优先、拨回归一、
跨会话隔离、持久化/forget 全过；相关既有测试（market/ccplugin/voice/bridge/store/
session 系）全过。

隔离实例端到端（独立数据目录，17 项断言全过）：A 关 B 开、全局不受影响、
`?s=` 资产放行/404、拨回恢复跟随、不存在的会话 404、删会话清覆盖。

浏览器实测：加号菜单项与 ✓；浮窗两页＋组件注册页（排在组件/插件之后）＋设置段；
A 会话关→热卸载（`__demoAlive` 0）、切别的会话→热装配（1）、切回 A→再卸载，
开关往返（覆盖删除、徽标消失）；设置页全局开关照常；切会话浮窗自动收起；
浮窗与设置页计算样式逐项一致（卡片 865.73×680/flex/14px 圆角/白底、导航 188px、
分区 padding 22px 26px、底栏边线同色）。

## 复验步骤

1. `go build .`、`go test -run 'TestSessionCX' .`
2. 起实例（任意数据目录），打开一个对话 → 加号 → 「本对话的组件与插件」→
   关「语音」→ 对话里语音按钮消失；侧栏切到没定制过的对话 → 语音按钮回来；
   切回 → 又消失。
3. 设置 → 内置组件：全局开关值全程不变。
